# Horae (Localized Fork) — "No More Chinese Bullshit" Edition

[English](README.en.md) | **Русский**

> *«Почему мой Казуха внезапно заговорил на китайском в конспектах?»* — Ответ прост: автор оригинала захардкодил промпты прямо в код. Мы это исправили.

Это форк расширения [SillyTavern-Horae](https://github.com/SenriYuki/SillyTavern-Horae). Мы его взяли, выпотрошили и отмыли от иероглифов везде, где они мешали жить.

### Что тут произошло:
*   **Удалили «китайщину» из промптов**: Теперь конспекты (summaries) и логи времени пишутся на нормальном человеческом языке, а не на языке страны-производителя.
*   **Починили краши**: Оригинал иногда ломался, если ты не китаец. Теперь не ломается.
*   **Векторная память больше не лагает иероглифами**: Все технические теги в поиске теперь локализованы. 
*   **Совместимость**: Если у тебя огромный чат, где уже есть старые записи на китайском — не ссы, расширение их всё ещё поймёт, просто новые будет писать нормально.

## Установка

1. В SillyTavern идёшь в расширения (пазл) -> **Install Extension**.
2. Кидаешь эту ссылку: `https://github.com/kykaaj/SillyTavern-Horae.git`
3. Жмёшь Install, обновляешь страницу и радуешься жизни без иероглифов.

## Заметка для разрабов (Localization)

Если полезешь в код что-то менять — **заклинаю тебя**, не пиши строки текстом прямо в коде. Используй `L()` для промптов или `t()` для интерфейса. Давай не будем возвращать китайский хаос обратно.

```js
// ✅ ТАК НАДО (выберет язык сам)
const msg = L('中文', 'English', '日本語', '한국어', 'Русский');

// ✅ И ТАК ТОЖЕ (для кнопок и менюшек)
showToast(t('common.saveSuccess'), 'success');
```
