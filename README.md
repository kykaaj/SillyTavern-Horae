# Horae (Localized Fork) — Memory Engine for SillyTavern

[English](README.en.md) | [Русский](README.ru.md)

This is a specialized fork of **Horae** designed to eliminate hardcoded Chinese prompts and ensure a smooth experience for English and Russian users.

---

### Почему этот форк? / Why this fork?

В оригинале многие системные промпты были "зашиты" на китайском, что вызывало иероглифы в конспектах и логах даже при смене языка в настройках. Мы это вылечили.

**English** | **Русский**
--- | ---
Cleaned all hardcoded Chinese prompts. | Вычистили все китайские промпты из кода.
Fixed locale-related syntax crashes. | Исправили вылеты на русской/английской локали.
Fully localized Vector Memory tags. | Перевели технические теги векторной памяти.
